# Elements

### Conversazione testuale nel terminale

La famiglia interagisce con Ambrogio da un terminale: invia turni testuali, osserva la risposta progressiva, consulta le conversazioni conservate e le continua. Il client usa soltanto le API HTTP pubbliche del backend; il backend e il client hanno repository e modelli Reqvire autonomi.
