# Elements

### Conversazione testuale nel terminale

La famiglia interagisce con Ambrogio da un terminale: invia turni testuali, osserva la risposta progressiva, consulta le conversazioni conservate e le continua. Il client usa soltanto le interfacce pubbliche del backend, cioè il protocollo conversazionale `ambrogio.v1` e le API HTTP di consultazione.
